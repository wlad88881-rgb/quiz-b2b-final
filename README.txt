ОБНОВЛЕНИЕ quiz-b2b-final  (полное, одним архивом)
==================================================
Распакуйте архив ПОВЕРХ папки проекта, согласившись на замену файлов:
    server.js
    db.js
    public/index.html
    public/student.html
Остальные файлы (public/*.html других страниц, package.json, *-content.js) не трогайте.
Новых npm-пакетов нет: npm install повторять не нужно.

ЧТО НОВОГО
1. Надёжность базы (db.js): атомарная запись, копии в data/backups (до 10 штук, раз в 5 минут),
   автовосстановление при повреждении db.json, отложенная запись на диск.
2. Время и ответы: сервер проверяет время теста (опоздавшие сдачи принимаются и помечаются
   в Excel колонкой «Сдан с опозданием, сек»). Режим разбора для студентов, выбирается
   при запуске сессии: сразу / только после завершения сессии / только баллы.
3. Безопасность: постоянный секрет входа (data/secret.key) — после перезапуска никого не
   выкидывает; пароля админки по умолчанию нет: если ADMIN_PASSWORD не задан, при первом
   запуске создаётся случайный, печатается в консоль и лежит в data/admin-password.txt.
4. Группы и списки студентов: кнопка «👥 Группы» (страница /groups). Вставляете список ФИО
   (можно из Excel) -> студенты входят по любому написанию имени, оно приводится к списку;
   посторонние и опечатки отсекаются с подсказкой. При запуске сессии выбирается, кто может
   войти: «по умолчанию» (активная группа), любая конкретная группа или «любой по ссылке».
   Блок «Кто пришёл и сдал» по коду сессии.
5. Аналитика: кнопка «📈 Аналитика» (страница /analytics), а также «📈 Аналитика» у каждой
   сессии теста в истории и в статистике. По сессии: средний результат, медиана, % верных по
   темам, сложные вопросы с частой ошибкой, студенты и слабые темы, Excel. По группе: журнал
   «студенты x тесты» с цветом, среднее, динамика, пропуски. Кнопка «Создать тест по слабым
   темам». Для работы по темам расставляйте теги в вопросах.
6. Надёжная сдача при плохой сети (student.html): перед отправкой ответы сохраняются на
   телефоне; при обрыве связи отправка повторяется сама и сразу при появлении сети, в том
   числе после перезагрузки страницы. Если сервер принял ответы, а ответ потерялся, результат
   подтягивается без повторной сдачи. Студент видит понятное сообщение.
7. Режим «разбор после завершения»: студент видит результат, а разбор ответов открывается
   на его странице сам (проверка раз в 30 секунд и кнопка), когда преподаватель завершит сессию.
   Для «только баллы» — поясняющее сообщение.

ВАЖНО
- Пока группа выбрана «по умолчанию» на странице /groups, она применяется ко всем новым
  сессиям. Для другой группы выберите её в окне запуска сессии или отключите привязку.
- Страницы тренажёров, чертежей и квалитетов для студентов (lab-student.html и др.) я не менял:
  отказ из-за списка группы они показывают текстом ошибки.
