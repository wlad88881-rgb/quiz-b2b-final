# Quiz B2B — платформа тестирования

## Что было доработано

1. **Загрузка тестов из Excel** — кнопка «Импорт Excel» на панели преподавателя теперь реально работает:
   загружает `.xlsx`, разбирает вопросы/варианты/правильные ответы (в т.ч. вопросы с несколькими
   правильными ответами) и открывает готовый тест в редакторе для проверки и сохранения.
   Кнопка «Шаблон Excel» скачивает файл с примером нужного формата.

2. **Рабочий QR-код, открывающий тест** — раньше файл `public/student.html`, на который вела
   ссылка/QR-код (`/s/:code`), просто отсутствовал в проекте, поэтому QR не открывал ничего.
   Он полностью написан заново: студент сканирует QR → вводит имя → проходит тест → видит
   результат с разбором ответов.

3. **Лимит времени на тест + автоотправка** — при запуске сессии преподаватель может указать
   лимит в минутах. У студента идёт обратный отсчёт; по истечении времени ответы отправляются
   автоматически, независимо от того, сколько вопросов отвечено.

4. **Переключение интерфейса RU/KZ + автоперевод вопросов** — на странице студента есть кнопки
   RU / KZ. Интерфейсные подписи переведены заранее, а сами вопросы и варианты ответов
   переводятся на казахский автоматически через сервис перевода (MyMemory API) при первом
   переключении на KZ и кешируются на сервере, чтобы не переводить повторно.

   ⚠️ **Важно:** перевод вопросов работает только там, где у сервера есть выход в интернет
   (например, на Render). В песочнице разработки внешние запросы к сервису перевода блокируются,
   поэтому логика перевода была протестирована на отказоустойчивость (при недоступности сервиса
   показывается оригинальный русский текст, а не ошибка).

## Дополнительно исправлено по пути

- Баг: при отметке нескольких правильных вариантов в редакторе теста сохранялся только первый
  ответ, а вопрос всегда сохранялся как «один правильный ответ». Теперь сохраняются все отмеченные
  варианты, и такие вопросы автоматически показываются студенту с чекбоксами.
- Кнопки «Завершить» и «Экспорт в Excel» на экране сессии были заглушками — теперь реально
  завершают тестирование и скачивают результаты.
- Скачивание шаблона Excel было сломано (не передавался идентификатор компании) — исправлено.
- Добавлено живое обновление списка участников на экране сессии преподавателя через Socket.IO
  (видно, кто присоединился и кто уже сдал тест, без обновления страницы).
- Раздел «Тренажёры» (лабораторные работы) не входил в ваш список требований и был изначально
  не полностью реализован в проекте (не было ни файла для прохождения, ни формы создания на
  панели преподавателя) — сейчас клик по нему не ломает страницу, но сам раздел как был, так и
  остаётся зоной для будущей доработки, если он вам нужен.

## Запуск локально

```bash
npm install
npm start
```

Откройте `http://localhost:3000` — это панель преподавателя (регистрация/вход).

## Деплой (например, Render)

Ничего менять не нужно — используется тот же `PORT`/`RENDER_EXTERNAL_URL`, что и раньше.
Просто убедитесь, что у сервиса есть исходящий доступ в интернет (для QR-ссылок и перевода на
казахский).

## Формат Excel для импорта вопросов

Столбцы: `Вопрос | Вариант 1 | Вариант 2 | Вариант 3 | Вариант 4 | Вариант 5 | Правильные (номера через запятую)`.
Один номер — вопрос с одним правильным ответом, несколько через запятую (например `2,4`) —
вопрос с несколькими правильными ответами.
